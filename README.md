# Мессенджер

Простой веб-мессенджер на Django с системой авторизации и реал-тайм обновлением сообщений.

## Функции

- Регистрация и авторизация пользователей
- Отправка сообщений между зарегистрированными пользователями
- Реал-тайм обновление списка сообщений (AJAX polling каждые 5 секунд)
- Просмотр всех отправленных и полученных сообщений
- Защита от CSRF-атак

## Требования

- Python 3.8 или выше
- Django 6.0+
- Виртуальное окружение (venv)

## Установка

1. **Клонируйте репозиторий** (или скачайте файлы проекта):
   ```
   git clone <URL_репозитория>
   cd messenger_project
   ```

2. **Создайте виртуальное окружение**:
   ```
   python -m venv venv
   source venv/bin/activate  # На Linux/Mac
   # venv\Scripts\activate  # На Windows
   ```

3. **Установите зависимости**:
   ```
   pip install django
   ```

4. **Выполните миграции базы данных**:
   ```
   python manage.py makemigrations
   python manage.py migrate
   ```

## Запуск

1. **Запустите сервер разработки**:
   ```
   python manage.py runserver
   ```

2. **Откройте браузер** и перейдите по адресу:
   ```
   http://127.0.0.1:8000/
   ```

## Использование

1. **Регистрация**: Перейдите на `/register/`, введите имя пользователя, пароль и подтверждение пароля.

2. **Вход**: На `/login/` введите свои учетные данные.

3. **Чат**:
   - Выберите получателя из списка пользователей.
   - Введите текст сообщения.
   - Нажмите "Отправить".
   - Сообщения обновляются автоматически каждые 5 секунд без перезагрузки страницы.

4. **Выход**: Нажмите "Выйти" в верхней части страницы.

### Тестирование в нескольких вкладках

- Зарегистрируйте двух пользователей.
- Откройте мессенджер в двух разных вкладках браузера под разными аккаунтами.
- Отправляйте сообщения — они будут появляться в обеих вкладках автоматически.

## API эндпоинты

- `GET /` — Главная страница чата (требует авторизации)
- `GET /login/` — Страница входа
- `POST /login/` — Обработка входа
- `GET /register/` — Страница регистрации
- `POST /register/` — Обработка регистрации
- `GET /logout/` — Выход
- `POST /send/` — Отправка сообщения (AJAX)
- `GET /messages/` — Получение списка сообщений (AJAX)

## Безопасность

- CSRF-защита включена для всех форм.
- Авторизация обязательна для доступа к чату.
- Пароли хэшируются Django.

## Разработка

Для внесения изменений:
- Измените код в соответствующих файлах.
- Выполните `python manage.py makemigrations` и `python manage.py migrate` при изменении моделей.
- Перезапустите сервер после изменений.
